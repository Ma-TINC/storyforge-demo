# StoryForge · 文化游戏工坊

StoryForge 是滴水湖全球OPC人工智能挑战赛（雪窦山 AIGC 品牌出海赛道 · 方向一：AI 智能体工具）的参赛作品：

**输入一个文化主题，自动生成可玩、可多语种发布的 HTML5 游戏。**

## 🎮 在线试玩

👉 https://Ma-TINC.github.io/storyforge-demo/mecha.html

**《龙甲·东方机甲·寻踪》** —— 中国文化机甲战斗题材互动游戏

- 中文 / English / 日本語 / 한국어 四语种内置
- 回合制战斗：动作动画（攻击 / 蓄力 / 防御 / 受击）、战斗对话气泡
- 双战斗推进：试炼·铁壁金乌 → 决战·黑翼暗枭
- 程序化 SVG 机甲立绘：玄龙（龙角 · 覆鳞 · 太极核心 · 披帛）vs 暗枭（鸦角 · 羽翼 · 爪刃）
- 道具收集 + 隐藏结局：集齐三件信物，解锁「龙魂觉醒」
